Import is the install

Paste import 0x…/file.bend. The compiler fetches that hash from the hub and verifies it.

Git until it publishes

If there is no 0x… yet, clone the repo and import a local path.

FAQ

Common questions

How do I use a package?+

There is no bend install yet. Copy the import 0x…/file.bend line into your program. bend fetches it from the hub when you check or run.

Is this the official Bend registry?+

No. Official surfaces are bend-lang.com, the hub, and bendlang/bend. This is a community catalog.

How does a package get listed?+

Hub listings come from hub.bend-lang.com/index.json. We attach GitHub when a repo README or the published file names that hash. Git clones without a live hash sit behind the source filter.

What is Nix doing in some tools?+

Nix pins a whole toolchain (compiler, clang, optional CUDA) so a machine rebuilds the same way. It is not how you add a Bend library. For libraries you paste an import hash, or clone git.
