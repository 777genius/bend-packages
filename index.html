FAQ

Common questions

How do I use a package?+

Use Copy import on a package card and paste the complete line into your Bend file, including the as Lib module alias. The line pins a published version or content hash. When a publication has no documented entrypoint, use View on Hub to inspect its files before choosing an import. The official Hub guide explains publishing and named packages.

Is this the official Bend registry?+

No. Official surfaces are bend-lang.com, the hub, and bendlang/bend. This is a community catalog.

How does a package get listed?+

The catalog combines curated entries from Awesome Bend with named publications from the official Hub. Daily refreshes sync descriptions, reviewed imports, and Hub metadata. Use Add package to suggest a missing project.

Will a package work with my Bend version?+

Check the project’s README and compiler requirements before changing a working pin. Copyable imports are checked against published file checksums. Compiler compatibility comes from the package’s documentation and your own checks.

What is Nix doing in some tools?+

Nix pins a toolchain, including the compiler and any native dependencies, so it can be reproduced on another machine. Follow the project’s setup instructions; Hub libraries use the pinned import shown on their cards.
